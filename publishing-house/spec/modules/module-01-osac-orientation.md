# Module 01 — OSAC Platform Orientation

### Brief Overview

This module introduces participants to the Open Sovereign AI Cloud (OSAC) platform. Participants log in to the admin console, explore the main navigation areas, and review the high-level architecture that connects OSAC to its OpenShift foundation. The module is intentionally short — its purpose is to orient participants and confirm the lab environment is functional before they tackle hands-on tasks.

### Audience and Time

**Audience**: OSAC administrators, platform engineers, and operations teams. Participants should have basic OpenShift console familiarity (navigation, namespaces).

**Duration**: 10 min

### Learning Objectives

- Explore the OSAC administrative console and identify key interface sections (tenants, templates, networks, VMs)
- Describe how the OSAC platform relates to its underlying OpenShift infrastructure
- Verify that both the admin account and end-user account are accessible and the lab environment is ready to proceed

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1 | Log in and navigate the OSAC console | 4 min |
| 2 | Review platform architecture | 3 min |
| 3 | Verify lab environment readiness | 3 min |

### Detailed Steps

1. Log in to the OSAC administrative console using the admin credentials provided in the lab environment.
2. Identify and briefly explore the main navigation sections: Tenants, VM Templates, Virtual Networks, and Virtual Machines.
3. Review the architecture overview (platform summary page or instructor-provided diagram) to understand the relationship between OSAC and OpenShift.
4. Log in to the end-user account to confirm it is accessible — then return to the admin account.
5. Confirm the lab environment is healthy and ready to proceed to Module 2.

### Key Takeaways

- OSAC is a sovereign cloud platform built on Red Hat OpenShift that delivers multi-tenant VM infrastructure.
- The admin console provides unified management across tenants, templates, networks, and VMs.
- Both an admin account and an end-user account are available throughout the lab to demonstrate different operational perspectives.
- The platform is pre-deployed — no installation is required; participants start directly with platform operation.

### Infrastructure Notes

- Participants access a pre-deployed OSAC environment; no cluster setup is needed.
- Both an admin credential and an end-user credential are provided in the lab environment details.
